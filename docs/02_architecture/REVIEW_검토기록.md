## 3. 발견 사항

| ID | 위치 | 내용 | 처리 |
|---|---|---|---|
| REV-A-01 | SWA 6.3 | DEGRADED 중 충돌 CONFIRMED를 받을 수 있는지 | DEGRADED는 유효 입력이 없는 상태이므로 새 충돌을 알 수 없음. 유효 입력이 오면 그 입력으로 판정(CONFIRMED면 즉시 1순위). 문서에 명시 |
| REV-A-02 | SWA 6.1 | override 주석이 더 높은 state를 덮어쓸 위험 | `decision.state`가 NORMAL일 때만 OVERRIDE를 붙이도록 명시 |
| REV-A-03 | SWA 4.1 | 50 ms 루프가 QM `web`에 있어 SWR-023(ASIL B) 할당이 섞임 | 주기 판정(`step`)은 ASIL B `controller`, 루프 구동만 QM. 시험은 `web` 없이 수행(TRACE 1장 주석) |
| REV-A-04 | SWA 6.3 | 상태 전이도에 모든 전이를 그리면 읽기 어려움 | 주요 전이만 그리고 일반 규칙(우선순위로 state 결정)을 글로 명시 |

## 4. 결론

SWE.2 산출물은 G2(BL-SWA-1.0, 정적 분석 계획 포함) 제출 조건을 갖췄다. 상세 설계(SWE.3, BL-SWD-1.0)는 3단계에서 작성한다.
