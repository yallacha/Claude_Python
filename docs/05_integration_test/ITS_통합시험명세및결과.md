# ITS SW 통합 시험 명세 및 결과

| 항목 | 내용 |
|---|---|
| 문서 ID | ITS-001 |
| 대상 | `childlock` 컴포넌트 10개 통합 (BL-SWA-1.0) |
| 베이스라인 | BL-INT-1.0 |
| 시험 코드 | `tests/integration/test_integration.py` |
| 환경 | PC/SIL, Windows 11, Python 3.12.10, 수동 시계(`ManualClock`), FastAPI 시험 클라이언트 |

## 1. 통합 전략

- **방식**: 단위 시험을 마친 컴포넌트를 실제 객체로 연결한다. 대역은 QM 고장 주입(IT-06)에만 쓴다.
- **순서**: 판정 코어(`validation`·`freshness`·`decision`) → `controller` → QM(`override`, `event_store`) → `web`(HTTP)·`replay`
- **검증 대상**: SWA 5장 컴포넌트 인터페이스, 6장 동적 동작, 7장 타이밍·자원, 10장 간섭 배제
- **합격 기준**: 모든 시험 통과, 커버리지는 단위 시험과 합산해 브랜치 100% 유지

## 2. 시험 사례와 결과

| ID | 목적 | 검증 대상 (SWA) | 관련 SWR | 결과 |
|---|---|---|---|---|
| IT-01 | HTTP 입력 → 검증 → 판정 → 상태 → 이력이 한 주기에서 일치 | 5장 인터페이스, 6.1 시퀀스 | SWR-001, 010, 014 | 통과 |
| IT-02 | 주행 자동잠금 → 성인 해제 → 접근위험 잠금 → 충돌 해제의 우선순위 흐름 | 6.2 우선순위 | SWR-003, 005, 007, 017, 022 | 통과 |
| IT-03 | state 전이 OFF→NORMAL→OVERRIDE→NORMAL→DEGRADED→NORMAL→FAULT→NORMAL→CRASH_RELEASE→OFF | 6.3 state 전이 | SWR-006, 007, 013, 020, 021, 024 | 통과 |
| IT-04 | override 주석이 HTTP 상태에 반영되고 출력(LOCK)은 그대로 | 5장, 10장 간섭 배제 | SWR-006, 009 | 통과 |
| IT-05 | 101주기 후 HTTP 이력 조회가 최신 100건 오름차순 | controller↔event_store↔web | SWR-010, 012 | 통과 |
| IT-06 | QM 이력 저장소 고장 주입 시 판정·상태 조회 정상, 고장 로그 기록 | 8장 오류 처리, 10장 | SWR-007, 014 | 통과 |
| IT-07 | 평가 1회 실행 시간 최대 5 ms 이하 (1,000회, 명령 2건·접근위험 교대) | 7장 자원 예산 | SWR-023 | 통과 |
| IT-08 | 실행 중 작업 폴더에 파일 생성 없음 | 7장, AD-06 | SWR-012 ④ | 통과 |
| IT-09 | 주기 안 시점(0, 10, 49 ms)과 무관하게 CONFIRMED 후 300 ms 이내 RELEASE | 7장 타이밍 | SWR-007, 023 | 통과(3건) |
| IT-10 | 200 ms 초과 무입력 후 100 ms 이내 DEGRADED | 7장 타이밍 | SWR-013 ③, 023 | 통과 |
| IT-11 | 모든 규칙을 거치는 시나리오 1,000회 재생 해시 동일 | AD-01, AD-03 | SWR-016 | 통과 |

**합계**: 13건 실행(IT-09 매개변수 3건 포함), 13건 통과, 실패 0.

## 3. 측정값

| 항목 | 값 | 기준 |
|---|---|---|
| 평가 1회 실행 시간 (10,000회 별도 측정) | 평균 30.6 µs, p99 39.8 µs, 최대 636 µs | 최대 5 ms (주기 50 ms의 10%) |
| 충돌 확정 → RELEASE | 최대 50 ms (다음 평가 주기) | 300 ms |
| freshness 상실 → DEGRADED | 200 ms 초과 후 최대 50 ms (첫 DEGRADED 250 ms) | 100 ms |

최대 실행 시간 636 µs는 OS 스케줄링에 따른 일시 지연으로 보이며 예산의 13% 수준이다.

## 4. 추적성: SWA → 통합 시험

| SWA 항목 | 통합 시험 |
|---|---|
| 5장 컴포넌트 인터페이스 (validation, freshness, decision, override, event_store, controller, web) | IT-01, IT-04, IT-05 |
| 6.1 평가 시퀀스 | IT-01 |
| 6.2 우선순위 판정 | IT-02, IT-11 |
| 6.3 state 전이 | IT-03 |
| 7장 타이밍·자원 | IT-07, IT-08, IT-09, IT-10 |
| 8장 오류 처리 | IT-06, IT-11(무효 입력) |
| 10장 간섭 배제 | IT-04, IT-06 |
| AD-01·03 결정론 | IT-11 |

SWA 동적 동작·타이밍·간섭 배제 항목이 모두 통합 시험으로 덮인다.

## 5. 발견 결함

통합 시험에서 발견된 결함은 없다.
